### To change directories (folder you are currently at):
```cd [file_name]/```

### To go to previous directory:
```cd ../```

### To know which directory you're at:
```pwd```

### To list files and directories
```ls```

### To create new directory (folder) called 'class_exercises':
```mkdir class_exercises```

### To delete directory:
```rm -r [file_name]/```

### To open file:
```less file_name```

### To print what is in a URL:
```curl "URL"```

### To save the URL content into a file:
```curl -o OUTPUT_FILENAME "URL"```

### To move file to a different directory:
```mv file_name location/```
